# Project 3: Student Data Organizer

## 📌 Project Description
The Student Data Organizer is a Python-based project designed to manage student information efficiently. It provides a menu-driven interface that allows users to perform different operations on student records.

## 🎯 Objectives
- To store student information.
- To display all student records.
- To update student information.
- To delete student records.
- To manage and display subjects offered.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Editor:** Visual Studio Code

## ✨ Features
1. **Add Student:** Enter and store student details such as ID, name, age, grade, date of birth, and subjects.
2. **Display All Students:** View the details of all stored students.
3. **Update Student Information:** Modify existing student details.
4. **Delete Student:** Remove a student's record.
5. **Display Subjects Offered:** View the available subjects.
6. **Exit:** Close the program.

## ▶️ How to Run the Project
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

   ```bash
   python "project 3.py"
   ```

6. Select an option from the menu and follow the instructions.
